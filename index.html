Diagnóstico por foto

Toma la foto de cerca, con buena luz, mostrando la parte dañada (hoja por ambos lados, fruto, tallo o raíz).

⚙️ Activar IA gratuita para fotos
  1. Entra a aistudio.google.com/apikey con tu cuenta de Google.
  2. Toca Create API key (es gratis, no pide tarjeta).
  3. Copia la clave y pégala aquí.

La clave se guarda solo en este dispositivo. El plan gratuito tiene un límite diario de consultas.
